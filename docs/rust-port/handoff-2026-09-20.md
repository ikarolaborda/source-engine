The script opens the main menu, enables full captions and raw mouse input, and

## Achieved in the implementation checkpoint

- All eight available game targets built and installed: `hl2`, `hl2mp`, `hl1`,
  `hl1mp`, `episodic`, `portal`, `cstrike`, `dod`. CI includes their build matrix.
  Episode One and Episode Two share the `episodic` binaries.
- Startup content mounts now follow gameinfo rather than HL2-only paths.
  Isolated writable runtime paths protect the original Steam content/configs.
- Rust owns generic LZSS/Snappy buffers and synchronous/split app-system
  lifecycle state, including rollback and duplicate/reentrant cleanup guards.
  Subsystem implementation bodies remain native.
- Rust owns ZIP/BSP metadata parsing, retained archive descriptors, payload
  reads, stored/LZMA decoding, CRC checks, cursors, wildcard traversal and
  numbered ZIP discovery. Ordinary mounts and explicit pack reads share one
  archive owner instead of reopening and reparsing it.
- Rust owns path-ID selection, traversal plans, duplicate-store visit sets,
  live ordered mount tables, snapshot tables, resource lease lifetimes and
  positive store-ID allocation. Native resource clone/drop callbacks and public
  adapters remain transitional.
- The shared Metal lightmap corruption is fixed at texture-lock level. The
  engine can lock a whole atlas and edit selected tiles; previously, zeroed
  staging memory erased untouched tiles on unlock. Native-format writable locks
  now preserve existing bytes. This is not a `woodfloor005a` material workaround.

## Remaining work, in practical order

1. **Manual-play feedback on the installed fixes.** Confirm previously black
   surfaces with `mat_fullbright 0`, resolution selection/restart persistence,
   captions and menu-first startup. No need to screenshot every affected
   material; investigate shared renderer behavior first. Some reported black
   props may have a different cause; the lightmap reproduction does not prove
   every visual defect is resolved.
2. **Startup and frame-time performance.** The user reports approximately
   five-minute launches. Logs examined do not account for the entire delay.
   Shader/pipeline compilation is synchronous and persistent caches remain
   absent. Profile the actual slow phases before optimizing. The lightmap fix
   adds synchronized readback; measure its cost and, if needed, introduce
   correctly invalidated CPU backing storage without reintroducing tile loss.
   Expanded CPU/GPU texture-format layouts still use the old upload-only path.
3. **Input and movement.** Raw input is explicitly enabled as a workaround,
   not a proven fix for erratic mouse behavior. Movement felt slow to the user;
   no movement speeds were changed. Source defaults are normal 190, walk 150,
   sprint 320 units/sec. Separate input, simulation timing, frame pacing and
   perceived speed before changing gameplay constants.
4. **NPC speech and scripts.** Episode Two report is the antlion defense while
   vortigaunts heal Alyx, `ep2_outland_02`. Visible speech/audio correctness is
   unresolved. Walking/turning loops are not evidence. The HL2 Barney sequence
   stalled after the user acquired early weapons and killed a guard; do not
   treat that cheat-disrupted scene as proof of a migration regression. Missing
   debug shader and post-process `$basetexture` warnings remain unresolved and
   are not established causes of the black floor.
5. **Next filesystem ownership boundary.** Move physical-path/path-ID metadata,
   alias matching, duplicate/reposition registration policy, map CRC identities
   and archive reuse out of native code. Ordinary Rust read mounts still
   synchronize from native metadata. Retire native callbacks/adapters only when
   the resource/interface contract is actually replaced. Native trust handling
   is not a newly validated security boundary.
6. **Complete the original migration.** Native host/subsystem, audio, UI,
   material/scene, physics/collision, gameplay and tool ownership remain. ToGL
   is still present; Metal opt-in is not ToGL retirement. Continue shader/API
   coverage, GPU validation, multiplayer, real campaign transitions and native
   Windows/Linux support. Rust cross-target checks are not native engine ports.
   Runtime content is available only for HL2/Episode One/Episode Two; obtain
   content before claiming the other six games work. TF2 implementation/source
   is absent from this tree and remains a separate unfinished requirement.

## Working conventions

Prioritize implementation and cheap, targeted checks. The user will play and
report flaws. Do not routinely repeat long fuzz campaigns, full matrices or
scripted movement loops. Do not alter movement/brightness merely to mask a bug.
Do not overwrite runtime libraries while the user is playing.

For the configured incremental HL2 build/install:

```sh
PATH=/Users/ikarolaborda/.cargo/bin:$PATH \
  WAFLOCK=.lock-waf-build-rust-allgames python3 waf install
```

The Rust toolchain is pinned to 1.85.1. Use the named Waf lock; unrelated locks
may point at different outputs. Never expose an entire Waf lock in diagnostics:
its environment snapshot may contain secrets. Preserve licensed Steam content
and isolated saves/configs. The migration is not complete merely because this
checkpoint is committed and installed.
